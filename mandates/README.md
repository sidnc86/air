# Mandates and Sources

This folder indexes candidate laws, rules, standards, and guidance relevant to accessibility and real-estate procedure. It distinguishes official-source discovery from text verification, applicability review, and reuse permission. See [`SOURCES.md`](../SOURCES.md).

## Indexes

- [`legal-mandates-sources.md`](legal-mandates-sources.md): current source leads and verification caveats.
- [`national/README.md`](national/README.md): locally stored national documents.
- [`mh/README.md`](mh/README.md): locally stored Maharashtra and RERA references, including secondary commentary.
- [`state-rera-sources.md`](state-rera-sources.md): compact state authority and source index.

Local presence does not establish that a document is official, current, applicable, or cleared for redistribution. Do not copy case materials into this folder.
