# Roadmap

This roadmap describes the intended sequence and current status; a status label is not a substitute for review. Each phase requires review before the next begins.

**See [`VERSIONING.md`](VERSIONING.md) for version tracking and release workflow.**

## Phase 1: Safe Markdown foundation

**Status: Substantially complete.** The source-review backlog is recorded in [`mandates/legal-mandates-sources.md`](mandates/legal-mandates-sources.md); confirm that the file-and-reference inventory is complete before treating this phase as fully closed.

Add sourcing, attribution, privacy, contribution, and scoped licensing guidance; improve navigation; make existing source records honest about verification gaps; add a preliminary Maharashtra RERA complaint orientation; label the Braille chart as partial and distinguish U.S. ADA examples from Indian requirements. Keep `cases/` untouched. Finish with a file-and-reference backlog for manual review or further research.

## Phase 2: Verified pilot

**Status: In progress.** 

**Checkpoint Completed (2026-11-10):** Marbella case verification and statutory cross-linking complete. Three key statutes converted to markdown and verified:
- ✅ RPWD Act 2016 (Sections 40, 44-47) — National accessibility duty verified for complaint claims
- ✅ Real Estate Act 2016 (Sections 11-15) — Relief framework with accessibility annotations verified for complaint relief section
- ✅ NBC 2016 Section 13 — Lift Braille requirement verified via MOHUA 2021 cross-check

RERA-COMPLAINT.md now has full statutory traceability. See [CHANGELOG.md](CHANGELOG.md) v1.0.1-alpha for verification details and [legal-mandates-sources.md](mandates/legal-mandates-sources.md) for source status.

**Remaining Phase 2 Work:** Before expanding state-specific material or moving to Phase 3, reconcile conflicting source, text, applicability, provenance, and rights statuses. Review reuse terms for retained source files, extracts, archived pages, and project assets; record findings in the relevant source records. A public URL, attribution, or local Markdown conversion does not establish reuse permission. Verify current Maharashtra procedure and outstanding primary sources (UDCPR regulations, MahaRERA procedures), expanding only where the evidence and review capacity support it. Any case-derived public material requires separate explicit approval and must be created outside `cases/`.

## Phase 3: Public repository and accessible reading site

**Status: Not started; gated on Phase 2 review.**

After a publication set and repository history have been reviewed, establish public governance and a reading experience using approved material. Test accessibility with disabled people and do not claim conformance without evaluation.

## Phase 4: Assisted contributions

**Status: Not started; gated on a defined private review process.**

Design an accessible submission route with consent, private review, retention and deletion rules. Public changes must contain approved public material only; raw submissions remain private.

## Phase 5: Multilingual stewardship

**Status: Not started; gated on review capacity.**

Expand jurisdictions and translations incrementally with native-language, legal, technical, and lived-experience review. Track versions and maintain source links over time.
