# Roadmap

This roadmap describes the intended sequence, not a promise that a phase has been completed. Each phase requires review before the next begins.

## Phase 1: Safe Markdown foundation

Add sourcing, attribution, privacy, contribution, and scoped licensing guidance; improve navigation; make existing source records honest about verification gaps; add a preliminary Maharashtra RERA complaint orientation; label the Braille chart as partial and distinguish U.S. ADA examples from Indian requirements. Keep `cases/` untouched. Finish with a file-and-reference backlog for manual review or further research.

## Phase 2: Verified pilot

Review outstanding sources and rights, verify current Maharashtra procedure, and expand state-specific material only where primary sources and review capacity support it. Any case-derived public material requires separate explicit approval and must be created outside `cases/`.

## Phase 3: Public repository and accessible reading site

After a publication set and repository history have been reviewed, establish public governance and a reading experience using approved material. Test accessibility with disabled people and do not claim conformance without evaluation.

## Phase 4: Assisted contributions

Design an accessible submission route with consent, private review, retention and deletion rules. Public changes must contain approved public material only; raw submissions remain private.

## Phase 5: Multilingual stewardship

Expand jurisdictions and translations incrementally with native-language, legal, technical, and lived-experience review. Track versions and maintain source links over time.
